Browse and clean up your downloads from the terminal

How to use tgdctl browse: the yazi file manager, pointed at your tg-downloader library, with folders by channel, language, type and month, and a delete key that keeps the database in step with the disk.

Overview

tg-downloader saves every file into one flat folder. That is fine for the downloader but poor for people: thousands of files in a single list, with no way to ask "show me only the French ones". Instead of writing a custom viewer, this setup reuses an existing, well-tested file manager and adds two small pieces of its own.

yazi

A fast terminal file manager. It does all the navigating, filtering, sorting and marking. We did not write any of that.

Category folders

A generated tree of symlinks, rebuilt from the database each time you launch, so you can browse by channel, language, type or month.

Safe delete

The delete keys are rerouted to a small command that removes the file and records it in the database, so nothing is downloaded again.

Why not just delete files in any file manager? The downloader keeps a database of every file. If a file disappears from disk but the database still says "downloaded", the listener notices on its next restart and downloads it again. And deleting a symlink only removes the link, not the file. That is why this setup has its own delete key.

Quick start

Run it on the machine that hosts the downloads (not inside the Docker container), from the project folder:

uv run tgdctl browse
  1. The command rebuilds the category folders from the database and prints how many links each has.
  2. yazi opens on the views folder, showing by-channel, by-language, by-month and by-type.
  3. Move with h j k l (or the arrow keys), look around, mark files and delete them.
  4. Press q to quit.

yazi must be installed. It is already present on this Raspberry Pi (version 26.9.1). On another machine, see the yazi installation page. If it is missing, tgdctl browse tells you so and exits without touching anything.

To rebuild the folders without opening yazi, run uv run tgdctl views.

Navigating

yazi shows three columns: the parent folder on the left, the current folder in the middle, and a preview of whatever is under the cursor on the right. Moving right opens a folder; moving left goes back up.

KeysAction

l or → or EnterOpen the folder under the cursor
h or ←Go up to the parent folder
g gJump to the top of the list
GJump to the bottom
Ctrl+d / Ctrl+uHalf a page down / up
~Show the key help (searchable list of every key)
qQuit

The right-hand pane stays deliberately simple: for a folder it lists the files inside, for a file it shows the file type. It does not render PDF or EPUB pages. That keeps the Raspberry Pi responsive and needs no extra tools. To actually read a document, use the web UI.

Lost? Press ~ for the full key list. The three delete keys at the top are the ones added by this project.

Categories

The top level holds four folders. They are four different ways of looking at the same files: a file appears once in each.

FolderWhat is inside
by-channel/One folder per Telegram channel, named after the channel title.
by-language/One folder per detected language (en, fr, …). unknown holds files whose language could not be detected, such as scanned PDFs or formats without text extraction.
by-type/One folder per file extension: pdf, epub, …
by-month/One folder per month (2026-09), by the date the message was posted on Telegram. unknown if the date is missing.

One file, four places. The entries are symlinks to the same file. Deleting a file in one category removes it from all of them. Folders themselves can never be deleted.

New downloads appear on the next launch. The folders are a snapshot taken when you run tgdctl browse (or tgdctl views). Quit and start again to see files that arrived in the meantime.

Sort

Press , and then one letter. A capital letter reverses the order.

KeysAction
, a / AAlphabetical / reverse alphabetical
, s / SSmallest first / largest first
, m / MOldest first / newest first, by the file's modification time

Two kinds of date. The sort above uses the file's modification time on disk, which is roughly when it was downloaded. The by-month folders use the date the message was posted on Telegram. They usually agree, but not always.

Deleting safely

Deleting is the whole point of this tool, so it is built to be hard to get wrong. The delete keys do not remove anything themselves. They call a small command, tgdctl discard-path, which follows the steps below.

1. Mark what you want to delete

KeysAction
SpaceMark the file under the cursor and move down. Press again on a marked file to unmark it.
Ctrl+aMark everything in the current folder.
vStart a range: move with j / k to extend it, then press Esc to keep the range marked.
EscClear all marks.

With nothing marked, the delete key acts on the file under the cursor.

2. Press d and confirm

d, D and Delete all do the same thing. The screen switches to a list of what will be deleted. Press y to go ahead; any other key cancels.

What the safe delete guarantees

  • The database is updated first. Each file is marked discarded with the reason manual:fs in a single transaction, and only then removed from disk. If the database is busy ("database is locked"), nothing is deleted and you are told so.
  • It never comes back. Because the database knows the file was discarded on purpose, the downloader will not fetch it again.
  • Links are followed. Selecting a file in by-channel deletes the real file and cleans up the links in all four categories.
  • Only the downloads folder is touched. Anything whose real location is outside it is refused, even if you navigate there by accident.
  • Folders are refused. You cannot delete a whole channel folder by accident.

Deleting is permanent. There is no trash and no undo. The file is gone from disk and its database record is marked discarded, so it will not be downloaded again either. Use Tab and the file name to double-check before you press y.

Keys that are switched off

Cut, paste, rename and create would move or rename real files behind the database's back. In this setup x, p, P, r and a do nothing.

One caveat. yazi's : command line can still run any shell command, and you can still navigate out of the views folder. The safe delete refuses to touch anything outside the downloads folder, but a shell command you type yourself is not checked.

Recipes: how do I…?

Common tasks, start to finish. Click a title to open it.

Delete everything from one channel
  1. Run uv run tgdctl browse, open by-channel and then the channel.
  2. Press Ctrl+a to mark every file.
  3. Press d, read the list, press y.

The channel stays subscribed; only its files are removed. New posts will still arrive.

Delete all files of one language
  1. Open by-language and then the language folder, for example fr.
  2. Ctrl+a, then d, then y.

Use unknown to review the files whose language could not be detected.

Free up disk space: find the biggest files
  1. Open by-type and then pdf (or epub).
  2. Press , then S: the largest files come first, with their sizes on the right.
  3. Mark the ones you no longer need with Space, then d, y.
Clear out an old month
  1. Open by-month and then the month, for example 2026-07.
  2. Ctrl+a, d, y.

Repeat for each month. Whole month folders cannot be deleted in one go, by design.

Delete just the one file I am looking at

Move the cursor onto it and press d then y. With no marks, the delete key acts on the file under the cursor.

Look at a document before deciding

The terminal browser does not render pages. Press Tab for file details, or open the web UI on port 8090, which has cover thumbnails and an in-browser PDF reader. Both tools use the same database, so a file deleted in one disappears from the other.

Find one file by name

In by-type/pdf (or any folder) press f and type a few letters of the name. Press Enter to keep the filter, mark or delete what remains, then Esc to clear it.

This setup uses its own yazi configuration (the yazi/ folder), loaded only by tgdctl browse. Your everyday yazi, if you have one, is unaffected.

Customizing

Edit yazi/keymap.toml. In yazi 26 the section is named [mgr]. Keep the delete keys pointed at "$TGD_DISCARD"; pointing them at yazi's built-in remove would bring back the problems described in the overview. The yazi keymap reference lists every available action.

Troubleshooting

"yazi is not installed"
Install it with your package manager (see the installation page) and run the command again.
A new download is missing
The folders are rebuilt when you launch. Quit with q and run tgdctl browse again, or run tgdctl views.
"Nothing deleted: database is locked"
The downloader was writing to the database at that moment. Nothing was removed. Press any key and try again.
"skipped … outside the downloads directory"
You navigated out of the library and tried to delete there. That is refused on purpose.
"skipped … is a directory"
Folders cannot be deleted. Open it, mark the files inside, and delete those.
A key does nothing
x, p, P, r and a are switched off on purpose.
Some files on disk are not in any category
The categories list what the database records as downloaded. Files that sit in the downloads folder without such a record (for example leftovers from earlier discards) do not appear.
A deleted file came back
That happens only if it was removed outside this tool (for example with rm): the database still said "downloaded", so the listener downloaded it again. Delete it again with d.
"Permission denied" on delete
Removing a file needs write permission on the downloads folder, even if the file itself belongs to another user. Check the folder's permissions.

Glossary

yazi
The terminal file manager used here.
Symlink
A small pointer to another file. The category folders contain only symlinks; deleting the pointer would leave the real file untouched, which is why the safe delete follows it.
Marked file
A file you selected with Space (yellow bar) so one command can act on several at once.
Discarded
The database status of a file that was deleted on purpose. The downloader never fetches a discarded file again.
Listener
The background service that downloads new files from Telegram.
Views
The generated folders (by-channel and so on) that yazi browses.
